## 2. Logic Chain

1. **Tageskarten Navigation**:
   - The grower needs to inspect past, present, or future day plans (Days 0–80).
   - Day selection control combines quick-phase tabs (Keimung, Veg, Hauptblüte, Spätblüte), step controls (`◄`, `Heute`, `►`), a day slider, and a horizontal Tageskarten card strip.
   - For any selected day, target values are derived via `getTargetsForDay(day, plan)` using `DayPlan` or phase target fallback matrix.

2. **3-Step Daily Workflow**:
   - **Step 1 (Tages-Check & Sollwerte)**: Renders phase summaries, photoperiod details, target metric corridors with `MetricGauge`, and inline tooltips via `TermTooltip`.
   - **Step 2 (Messwerte & Beobachtung erfassen)**: Provides interactive input controls for physical metrics (Air Temp, Humidity, Leaf Temp, PPFD, pH, EC, Water, Drain, Pot mass, Plant height, Stress). Automatically calculates Leaf Delta VPD and Drain %. Provides a structured observation sub-form for logging tagged visual observations. Triggers immutable updates via `addObservation` and `addStructuredObservation`.
   - **Step 3 (Maßnahmen & Bestätigung)**: Renders interactive task checklist driven by `setTaskCompleted` and `transitionTaskState`. Displays daily nutrient recipe quick-view generated by `calculateMix`. Displays persistent alerts via `deriveRunAlerts` with `acknowledgeAlert` capability. Provides final daily completion confirmation.

3. **Experience Lens Adaptations**:
   - `guided`: Plain German guidance cards, prominent tooltips, simplified task views.
   - `advanced`: Detailed metric breakdown, drain % targets, leaf delta adjustment.
   - `expert`: Full telemetry details, target range formulas, audit event previews, and evidence ratings.

4. **Immutability & Safety**:
   - State updates never mutate `run` directly. All changes pass through pure state helper functions in `src/run-state.ts` and dispatch to `onUpdateRun`.
