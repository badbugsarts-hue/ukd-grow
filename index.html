Lokaler Webserver erforderlich

Diese Datei ist der Einstiegspunkt einer React/TypeScript-Anwendung und kann wegen Browser-Sicherheitsregeln nicht direkt über file:// ausgeführt werden.

Öffne im Windows-Explorer im Projektordner die Datei START_UKD.cmd. Sie startet den lokalen Server und öffnet die Anwendung automatisch im Browser.

Alternativ im Terminal: pnpm start:local
